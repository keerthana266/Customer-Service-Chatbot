# Customer Service Chatbot

A simple NLP-based Customer Service Chatbot built using Flask, TF-IDF, and cosine similarity.
It can answer basic customer queries like orders, refunds, products, and pricing.

## Project Overview

This chatbot is designed to simulate a basic customer support system.
It uses Natural Language Processing (NLP) techniques to understand user queries and return relevant responses from predefined intents.

It is suitable for:
Customer service automation
Learning NLP basics

## Features

- Chat interface for user queries
- TF-IDF based intent matching
- Handles customer queries (orders, refund, products, pricing)
- Flask web application
- Deployed on Render

---

## Tech Stack

- Python
- Flask
- NLTK
- Scikit-learn
- TF-IDF Vectorizer
